# Domain Docs

Look up the domain terms you use in `CONTEXT.md` and the two glossaries it links; ADRs in `docs/adr/` record decisions that are hard to reverse.

- Name domain concepts (in issues, proposals, test names) with the glossary's terms, not the aliases it lists under _Avoid_.
- If a concept you need is missing, either you are inventing language (reconsider) or there is a gap: add a short entry to the glossary file it fits.
- If your output contradicts an ADR, say so explicitly rather than silently overriding it.
