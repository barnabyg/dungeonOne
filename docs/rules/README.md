# 5e rules

Dungeon One uses the 2024 fifth-edition rules in SRD 5.2
([ADR 0005](../adr/0005-start-afresh-on-5e-and-suspend-compatibility.md)). These
files record the rules the code doesn't make plain: house rules, departures from
SRD 5.2, omissions and engine abstractions. The code and data hold the numbers.
Read the file for the topic you are changing.

This work includes material from the System Reference Document 5.2 ("SRD 5.2")
by Wizards of the Coast LLC, available at https://www.dndbeyond.com/srd. The SRD
5.2 is licensed under the Creative Commons Attribution 4.0 International
License, available at https://creativecommons.org/licenses/by/4.0/legalcode.

  settling.
- [Classes](classes.md): the Fighter and Rogue: what their features do in the

- [Casting classes](classes-casters.md): the same for the Cleric and Wizard.

- [Treasure and magic items](treasure.md): treasure and its budget, magic items,

- [Combat](combat.md): turns, targeting, conditions, rests.
- [Morale, stealth and talk](talk-and-stealth.md): morale and surrender,
  sneaking and surprise, reaction rolls, parley, tolls and trade.
- [Spellcasting](spells.md): slots, preparing, casting, concentration, areas and

- [Exploring](exploring.md): the map, moving, regions, known rooms, doors, traps

- [Flags and wandering encounters](flags.md): flags, alarms, what changes with

- [Checks, item uses and fight actions](checks.md): graded checks, using an item

- [Adventure modules](modules.md): the module format and the validator's design

- [Bestiary](bestiary.md): the shared monsters, their sources and what is left

- [Balance gate](balance-gate.md): the verdict, class parity, sure-held items,

- [House rules](house-rules.md): departures from SRD 5.2.
- [Rules that need positions](positions.md): how rules that need distance are

- [Settings](settings.md): the Settings page, each adventure's frozen copy, and
