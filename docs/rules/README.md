# 5e rules

Dungeon One uses the 2024 fifth-edition rules in SRD 5.2 ([ADR 0005](../adr/0005-start-afresh-on-5e-and-suspend-compatibility.md)). These files record the rules the code doesn't make plain: house rules, departures from SRD 5.2, omissions and engine abstractions. The code and data hold the numbers. Read the file for the topic you are changing.

This work includes material from the System Reference Document 5.2 ("SRD 5.2") by Wizards of the Coast LLC, available at https://www.dndbeyond.com/srd. The SRD 5.2 is licensed under the Creative Commons Attribution 4.0 International License, available at https://creativecommons.org/licenses/by/4.0/legalcode.

- [Characters](characters.md): creation, XP and levels, leaving, coin and settling.
- [Classes](classes.md): what each class's features do in the engine, and what is omitted.
- [Gear and treasure](gear.md): weapons, armour, carrying, changing gear, treasure, magic items, scrolls, monster loot, merchants.
- [Combat and talk](combat.md): turns, targeting, conditions, morale and surrender, rests, sneaking and surprise, reaction rolls, parley, tolls and trade.
- [Spellcasting](spells.md): slots, preparing, casting, concentration, areas and SRD departures.
- [Exploring](exploring.md): moving, regions, flags, alarms, wandering encounters, checks, doors, traps and features.
- [Adventure modules](modules.md): the module format, the validator's design constraints and the bestiary.
- [Balance tools](balance.md): the harness, the gate and how to read its output, career simulation, encounter estimate.
- [House rules and positions](house-rules.md): departures from SRD 5.2, and the rules that need positions.
