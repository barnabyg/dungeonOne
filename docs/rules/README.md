# 5e rules

Dungeon One uses the 2024 fifth-edition rules in SRD 5.2 ([ADR 0005](../adr/0005-start-afresh-on-5e-and-suspend-compatibility.md)). This is the game's rules document: character creation, combat, exploration and items, checks, traps and talk, adventure modules and the balance gate, and the house rules and position rules that depart from SRD 5.2.

This work includes material from the System Reference Document 5.2 ("SRD 5.2") by Wizards of the Coast LLC, available at https://www.dndbeyond.com/srd.
