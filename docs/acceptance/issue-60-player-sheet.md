# Unfamiliar-player sheet for issue 60

Play one assigned adventure without reading its JSON, route tests, or the facilitator's notes. Use ordinary game commands and stop whenever you would naturally stop. The facilitator should record the actual duration; there is no target time. Say aloud what you think your goal is and why you choose each next step. The facilitator may explain only how to enter a command or operate the terminal, not where to go or what an action will reveal.

After play, answer these in your own words:

1. What did you think the goal was at the start? Did that change?
2. Which clues did you notice? Which clue made the next action clear or unclear?
3. Did you reach an ending? If not, where did you stop and why?
4. Were both ending choices visible to you? What did you expect each choice to change?
5. Did any description, person, item, or outcome contradict something you had already seen?
6. Did you encounter a dead end, an action you expected but could not perform, or an instruction you did not understand?
7. Was this story interesting enough that you wanted to finish? Why or why not?
8. If you played another sample, did the adventures feel different or interchangeable? What repeated?

The facilitator records the sample filename, participant code (no name required), prior familiarity with Dungeon One, mode (command or live AI), seed, start and stop time, whether hints were given, exact confusion or contradiction quotes, observed ending, and answers above. To capture commands without asking the player to take notes, add `--trace .scratch/issue-60/<participant-code>.json` to the launch command after creating that ignored directory. The game writes it when the session ends. Keep raw player transcripts and personal information outside source control. Summarize findings without identifying players in `issue-60.md` and rerun any corrected journey.
